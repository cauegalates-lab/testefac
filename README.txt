FACE ID WEB DEMO

COMO TESTAR:
1. Extraia o ZIP.
2. Suba index.html, style.css, app.js e vercel.json para um repositório GitHub.
3. Importe o repositório na Vercel.
4. Abra a URL HTTPS no Safari do iPhone.
5. Toque em "Cadastrar neste aparelho".
6. Autorize a Passkey usando a autenticação do iPhone.
7. Depois toque em "Entrar com Face ID".

IMPORTANTE:
- Esta versão é WEB/PWA, não um app iOS nativo.
- O navegador solicita a autenticação segura do aparelho.
- Em um iPhone compatível/configurado, o Face ID normalmente será usado.
- Em produção, desafio e validação devem acontecer no backend.
