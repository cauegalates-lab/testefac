FACE ID LOGIN DEMO

1. Publique estes arquivos em HTTPS (ex.: Vercel).
2. Abra a URL no Safari do iPhone.
3. Toque em "Cadastrar Face ID neste aparelho".
4. Autorize a Passkey usando Face ID.
5. Depois toque em "Entrar com Face ID".

IMPORTANTE:
Este é um protótipo front-end para demonstrar a chamada de Passkey/WebAuthn.
Em um sistema real, o desafio e a validação da credencial precisam acontecer no backend.
